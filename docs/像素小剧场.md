# 像素小剧场：完整用法

一条片子 = `src/projects/<slug>/` 里的一份 `script.ts`（加上配音用的 `voice.json`）。
这份文档讲脚本里能写什么、各部分怎么配合，以及做样片时踩过的坑。
完整的真实例子看 `src/projects/ruffood-story/script.ts`。

## 1. 整体结构

```ts
const base: VideoScript = {
  id: 'my-film',                       // composition id 前缀，小写加短横线
  title: '片名',
  fps: 30,
  theme: myTheme,                      // 必须是像素主题（style: 'pixel'）
  formats: ['landscape'],              // 小剧场按横版设计
  transition: {type: 'none', seconds: 0},
  music: 'audio/my-film/bed.mp3',
  musicVolume: 0.2,
  world: {...},                        // 房间、布景、角色，整片共用
  scenes: [...],                       // 一拍一场，type: 'stage'；最后可以接一张 end 标志卡
};

export const myFilmScript = voiced(base, timings as VoiceTimings, {breath: 0.4});
```

**世界状态一路往下传。** 第 5 场开始时，前 4 场所有的走位、表情、屏幕内容都已经发生过了。
所以每场只写「这一场里新发生什么」，不用重复交代前情。

## 2. 世界：`world`

```ts
world: {
  width: 3,                            // 房间多长，单位是屏宽
  props: [ /* 布景 */ ],
  cast: [ /* 角色 */ ],
}
```

**横坐标 `x` 一律以屏宽为单位，指物体的水平中心**：0.5 是第一屏正中，1.5 是第二屏正中。
画面高度固定分三段：墙（上 70%）、地板（70% 到 87%）、底栏（最下面 13%）。

### 布景 `props`

| kind | 是什么 | 额外字段 |
|---|---|---|
| `desk` | 书桌 + 显示器 + 台灯 + 笔筒，台灯带一圈暖光 | `screen`：显示器内容 |
| `screen` | 墙上大屏，深色木框 | `width`：占屏宽比例，默认 0.42；`screen`：内容 |
| `window` | 夜窗，方月亮，星星轮流闪 | |
| `board` | 软木板，几张彩色便签 | |
| `shelf` | 三层书架 | |
| `plant` | 盆栽 | |
| `item` | 小道具，站在地上 | `item`：道具名；`lift`：离地几格，放桌上给 17；`hidden: true` 先藏着，用 cue 让它出现 |

道具 `item`：`tub`（黄盖奶粉罐）、`bottle`（白瓶）、`pouch`（黑色立袋）、`takeout`（外卖袋）、`bowl`（狗碗）。

每个布景都要有唯一的 `id`，cue 靠它找到要换内容的屏幕、要出现的道具。

### 角色 `cast`

```ts
{id: 'bern', sprite: 'coder', name: '伯恩', x: 0.62, facing: 'left'}
```

| 字段 | 说明 |
|---|---|
| `sprite` | `coder` 程序员、`nutritionist` 白大褂、`dog` 小狗、`bot` 机器人、`slime` 果冻、`cat` 猫 |
| `name` | 对白框上的名牌，不给就不印 |
| `facing` | 初始朝向，`left` / `right` |
| `hidden` | 先不出场，之后用 `enter` cue 让他进来 |

角色一直在动：每半秒呼吸一下，每三秒多眨一次眼，说话时嘴一张一合，开口那一刻跳一下。

## 3. 一场戏：`type: 'stage'`

| 字段 | 说明 |
|---|---|
| `line` | `{who, text}`：谁说什么。对白框出在说话人头顶，字按配音逐字打出 |
| `camera` | `{x, zoom?}`：本场开头镜头平移过去。**写了 camera 没写 zoom 就回到 1**，推近只管一场 |
| `cues` | 场内动作，见下 |
| `chapter` | 底栏左侧章节牌，比如 `'① 一个程序员'`，挂到下一次换 |
| `console` | 底栏控制台逐字打出的一行，适合放年份和旁注 |
| `iris` | `'in'` 从黑里打开、`'out'` 收回黑里，以说话人为圆心 |
| `panel` | `{title?, rows[], at?}`：浮在画面上方的信息面板 |
| `banner` | `{text, sub?, at?}`：顶部居中的大字条 |
| `seconds` | 没配音时的兜底时长；接了 `voiced()` 之后由配音覆盖 |

### 场内动作 `cues`

每条都有 `at`：**本场里的位置，0 到 1**，不是秒数。改了台词、配音变长变短，动作跟着等比挪。

| 写法 | 效果 |
|---|---|
| `{at, move: 'bern', to: 1.2}` | 走到 x = 1.2，每秒走 0.55 屏宽，朝向自动转 |
| `{at, face: 'bern', mood: 'happy'}` | 换表情：`calm` 平静、`happy` 笑眯眼、`shut` 闭眼、`wide` 瞪眼 |
| `{at, turn: 'bern', facing: 'right'}` | 转身 |
| `{at, screen: 'wall', show: {...}}` | 换某块屏幕的内容 |
| `{at, enter: 'jane'}` / `{at, exit: 'jane'}` | 角色或道具出现、消失 |

### 屏幕内容 `show`

| kind | 字段 | 画面 |
|---|---|---|
| `off` | | 黑屏 |
| `code` | | 一直往上滚的代码行 |
| `text` | `title?`、`lines[]` | 标题加几行字，逐行出现 |
| `list` | `title?`、`items[{text, tone?}]` | 带方块的清单，`bad` 标红、`good` 标绿 |
| `bars` | `title?`、`items[{label, value, note?}]` | 横条，`value` 0 到 1，一格一格涨上去 |
| `items` | `items[{item, label?}]` | 一排像素道具，带标签 |
| `image` | `src` | 图片，按像素放大不做平滑，放像素风标志正合适 |

桌上显示器小，放 3 到 4 行短字；墙上大屏能放 4 到 5 行。

## 4. 配音和时长

1. `voice.json` 的 `lines` 按场景 id 写台词，必须跟 `line.text` 一字不差
2. `npm run tts -- --project <slug>`：合成到 `public/audio/<slug>/`，词级时间戳写进 `voice.timings.json`
3. 脚本用 `voiced(base, timings, {breath: 0.4})` 包一层：每场秒数 = 配音时长 + 呼吸

`breath` 是句与句之间的停顿。一个人一口气讲下来的故事给 0.3 到 0.5 秒，停太久像在念稿。
最后那张 `end` 标志卡不配音，保留脚本里写的秒数。

**`voice.timings.json` 和 `public/audio/` 是源文件，不是生成物。** 每次合成的时长都略有不同，
重新跑一次 tts，整条片子的节奏就跟着变。改完台词才重跑。

## 5. 音乐

```bash
python3 scripts/make-bed.py --style chiptune --bpm 100 --seconds <片长> --out public/audio/<slug>/bed.mp3
```

方波旋律、方波琶音、三角波低音、噪声鼓，红白机那套。编排分三段：前 15% 只有琶音和低音，
中段加鼓和旋律，最后 10% 收回去。片长用 `npx remotion compositions` 查，`--seconds` 必须等于片长。
音床归一化到 -14 LUFS，`musicVolume: 0.2` 时比人声低 12 LU 左右，正好垫在底下。

## 6. 主题和品牌色

```ts
import {pixelTheme, type Theme} from '../../kit/theme';

const myTheme: Theme = {
  ...pixelTheme,
  name: 'my-brand',
  colors: {...pixelTheme.colors, accent: '#FE6B34', accentInk: '#1B1726'},
};
```

`accent` 出现在名牌、章节牌、进度线、屏幕标题、条形图上。**别丢掉 `style: 'pixel'`**，像素风的开关就是它。

## 7. 验收

```bash
npm run check                                     # 类型检查
npm run render -- <slug> --still 12.5             # 截第 12.5 秒一帧
npm run render -- <slug>                          # 整片
python3 scripts/check-motion.py out/<slug>/landscape.mp4
ffmpeg -hide_banner -nostats -i out/<slug>/landscape.mp4 -af ebur128=peak=true -f null - 2>&1 | grep -A12 Summary
```

想知道某一场从第几秒开始：没接配音时把前面各场 `seconds` 加起来；接了配音看 `voice.timings.json`
里各场时长，加上 `breath`。截图选在一场的后半段，对白框已经打完、动作都发生过了。

响度目标：整片 -16 LUFS 左右，低于 -20 就太闷；真峰不超过 -1 dBFS。

## 8. 踩过的坑

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 对白框压住墙上大屏的字 | 角色太靠近大屏正下方，台词又长 | 让角色站到大屏一侧；台词压到两行以内 |
| 说话的人不在画面里，对白框贴在边上 | 他还在走，镜头先到了 | 把 `move` 的 `at` 提前，或者镜头对准他要去的位置 |
| 后面几场画面莫名放大、上沿被切 | 某场推近后，后面的场没写 `camera` | 推近那场的下一场写上 `camera`，zoom 不写就回到 1 |
| 浮层面板跟屏幕内容叠在一起很乱 | 两块信息抢同一片位置 | 信息优先放进屏幕，面板只在没有屏幕的位置用 |
| 对白框打字跟声音对不上 | `voice.json` 和 `line.text` 不一致 | 两边改成一字不差，重新跑 tts |
| 年份数字念得别扭 | TTS 按自己的规则读阿拉伯数字 | 两边一起改写法，比如「二〇一三年」 |
| 字体渲成黑体 | 主题没有 `style: 'pixel'`，像素字体没加载 | 从 `pixelTheme` 展开再改颜色 |
| 自己画的角色看不出是什么 | 16 格宽放不下细节 | 只留轮廓、两只眼、一个最有辨识度的特征 |

## 9. 其他场景类型

小剧场之外还有 14 种通用场景（`title`、`bullets`、`stats`、`features`、`pricing`、`tour` 截图巡览等），
在像素主题下全部自动换成像素外观，`chat` 会变成两个角色对话。样例在 `src/projects/_pixel/script.ts`，
字段定义看 `src/kit/script.ts` 的类型注释。它们适合做讲解片；讲故事用小剧场。
